# ACR Skills #

Claude Skills used by Alpine Computing Research.

| Name | Description | Path |
| --- | --- | --- |
| `business-ideas` | Generates business ideas in a fixed format: product or service, who pays, why they pay, how much they pay, and the edge. | [`skills/business-ideas`](skills/business-ideas) |
| `software-spec` | Ingests a software specification written in the [Good Software Specification Format (GSSF)](https://github.com/Alpine-Computing-Research/gssf), validating it and building a consolidated understanding before any implementation or review work. | [`skills/software-spec`](skills/software-spec) |
